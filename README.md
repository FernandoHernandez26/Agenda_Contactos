

# Agenda de Contactos

Aplicación de consola desarrollada en **Kotlin** para gestionar una agenda de contactos.

## Funcionalidades
- Añadir contactos.
- Mostrar todos los contactos.
- Buscar contactos por nombre.
- Eliminar contactos.
- Validar teléfono y correo electrónico.

## Estructura del proyecto
- `Main.kt`: inicia el programa.
- `Menu.kt`: gestiona el menú y las opciones.
- `Agenda.kt`: administra los contactos.
- `Contacto.kt`: define los datos de cada contacto.

## Validaciones
- El teléfono debe tener al menos 9 dígitos.
- El correo debe contener `@`.

## Ejecución
Ejecutar el archivo `Main.kt` desde IntelliJ IDEA o desde un entorno compatible con Kotlin.
